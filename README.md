Precursor to a 3D minesweeper game, inspired by [this one.](http://egraether.com/mine3d/)

1. Install Node.js dependencies:
   ```
   npm install
   ```

2. Start the server:
   ```
   npm start
   ```

The server will run on `https://localhost:8089`

- **WASD, QE** to move
- **Hold RMB** to pan the camera
